# jpi-base (absorbed)

The `jpi-base` library was absorbed into the consolidated
[jpi](https://github.com/josh-sola/jpi) plugin. New development happens
there.

This repo stays in place so existing `#semver:` tag resolutions keep
working for the plugins that still depend on published `jpi-base` tags:
`jpi-planter`, `jpi-sidebar`, and `jpi-recipes`. Its code, version, and
tags are unchanged and will not be bumped or added to going forward.
